## VOICE ROUTES  `prefix /voice`

### POST /voice/inbound  _(Twilio webhook — incoming call)_

- [ ] **Auth**: Twilio HMAC — `X-Twilio-Signature` vs `TELEPHONY_AUTH_TOKEN`; skipped if token blank (dev mode) → 403 on failure
- [ ] Parse form body (`CallSid`, `To`, `From`, `CallStatus`, …)
- [ ] `_resolve_company_id(To)`: `SELECT id FROM companies WHERE phone = To` → fallback `SELECT id FROM companies LIMIT 1`
- [ ] If no company: return fallback TwiML (`<Say>` + `<Hangup>`)
- [ ] `create_session(call_sid, company_id)` → `Redis SETEX call_session:{call_sid}` TTL 3600 s
- [ ] Build `<Connect><Stream>` TwiML pointing to `wss://{TELEPHONY_WEBHOOK_BASE_URL}/voice/stream/{call_sid}`
- **DB reads**: `companies` (phone lookup, fallback LIMIT 1)
- **DB writes**: Redis `call_session:{call_sid}`
- **Ext**: —
- **Response**: TwiML XML (`Content-Type: application/xml`)

### POST /voice/status  _(Twilio webhook — call ended)_

- [ ] **Auth**: Twilio HMAC (same as `/voice/inbound`) → 403 on failure
- [ ] Parse `CallSid`, `CallStatus`, `CallDuration`
- [ ] If `CallStatus` ∈ {`completed`, `failed`, `busy`, `no-answer`}:
  - [ ] `Redis GET call_session:{call_sid}` → deserialize `CallSession`
  - [ ] `_finalize_call(session, duration)`:
    - [ ] Join `session.transcript_parts` into `transcript_text`
    - [ ] If transcript not empty → **LLM** `claude-sonnet-4-6` (400 tok, temp 0.0): extract lead fields from transcript → JSON
    - [ ] Merge extracted fields with `session.lead_data`
    - [ ] If `session.lead_id`: `UPDATE leads SET …` else `INSERT INTO leads` (source=`voice`)
    - [ ] If lead_id + transcript: `INSERT INTO conversations` (channel=`voice`, full turns array, call_duration)
  - [ ] `Redis DEL call_session:{call_sid}`
- **DB reads**: Redis `call_session:{call_sid}`
- **DB writes**: `leads` (UPDATE or INSERT), `conversations` (INSERT), Redis DEL
- **Ext**: LLM `claude-sonnet-4-6` (lead extraction from transcript)
- **Response**: 204 No Content

### WS /voice/stream/{call_sid}  _(Twilio Media Streams — live call audio)_

- [ ] **Auth**: NONE (URL is Twilio-controlled; call_sid validated via Redis session lookup)
- [ ] `WebSocket.accept()`
- [ ] `Redis GET call_session:{call_sid}` → `CallSession`; if none → close WS
- [ ] `SELECT name FROM companies WHERE id=company_id`
- [ ] **Greeting**: `synthesize_to_mulaw(CALL_GREETING)`:
  - [ ] **Ext**: POST Deepgram Aura-2 `/v1/text-to-speech/{TTS_VOICE_ID}` (`eleven_turbo_v2_5`) → MP3
  - [ ] **Ext**: ffmpeg subprocess: MP3 → 8 kHz mulaw
  - [ ] Send mulaw frame to Twilio
- [ ] **Audio loop** (8-chunk buffer ≈ 1 s of audio per turn):
  - [ ] Receive Twilio `{"event":"media"}` frames; accumulate base64 mulaw chunks
  - [ ] Every 8 chunks → `transcribe_mulaw_b64(combined)`:
    - [ ] If < 160 bytes: skip (silence)
    - [ ] **Ext**: POST Deepgram `/v1/listen` (`nova-2`, mulaw 8 kHz) → transcript
  - [ ] If transcript not empty → `process_voice_turn(transcript, session)`:
    - [ ] **Ext**: `langdetect.detect()` + `GoogleTranslator` → English
    - [ ] `query_with_confidence(english_query, company_id, top_k=4)`:
      - [ ] **Ext**: POST OpenAI `/v1/embeddings` (`text-embedding-3-small`)
      - [ ] Qdrant `search` (`nexadesk_kb`, filter `company_id`, limit 12, threshold 0.30)
      - [ ] **Ext**: POST Jina `/v1/rerank` (`jina-reranker-v2-base-multilingual`) if `JINA_API_KEY` set → top 4
    - [ ] `SELECT * FROM companies WHERE id=company_id`
    - [ ] Build `RECEPTIONIST_SYSTEM_PROMPT` + `VOICE_SYSTEM_SUFFIX` (≤3 sentences, no markdown)
    - [ ] **Ext**: LLM `claude-sonnet-4-6` (max_tokens=150, temp=0.4) → `reply_english`
    - [ ] **Ext**: `GoogleTranslator` → reply in caller's language
    - [ ] Rule-based lead scoring → `session.score += delta`
    - [ ] Append turns to `session.transcript_parts`, update `session.lead_data` (regex extract name/phone/email)
    - [ ] `Redis SETEX call_session:{call_sid}` TTL 3600 s
    - [ ] `_send_tts(websocket, reply, call_sid)`:
      - [ ] **Ext**: Deepgram Aura-2 TTS → mulaw; on failure → **Ext**: Twilio REST `calls(call_sid).update(twiml=…)`
  - [ ] `{"event":"stop"}` → break loop
- [ ] **Finally**: flush remaining buffer → one last `process_voice_turn`; `Redis SETEX` updated session
- **DB reads**: Redis `call_session:{call_sid}`, `companies` (name, full record), Qdrant `nexadesk_kb`
- **DB writes**: Redis `call_session:{call_sid}` (after each turn)
- **Ext**: Deepgram Aura-2 TTS, Deepgram STT, OpenAI Embeddings, Jina Reranker, LLM ×3 per turn, Google Translate, ffmpeg, Twilio REST (TTS fallback only)
- **Response**: bidirectional WebSocket text/binary frames (Twilio Media Streams protocol)

## CHAT ROUTES  `prefix /chat`

### POST /chat/message  _(main chat widget endpoint)_

- [ ] **Auth**: NONE (public)
- [ ] Body: `{message, session_id?, company_id, lead_id?}`
- [ ] `session_id` = body value or `uuid4()`
- [ ] `Redis GET chat:session:{session_id}` → history list; on miss → `SELECT transcript FROM conversations WHERE session_id=…` → history[-20:]
- [ ] `SELECT * FROM companies WHERE id=company_id`
- [ ] `orchestrator.run(user_message, company_id, history, company, lead_id)`:
  - [ ] `normalize_for_llm()` → English + detected language
  - [ ] **asyncio.gather**:
    - [ ] `_route()` LLM (30 tok, temp 0.0)
    - [ ] `query_with_confidence()`: OpenAI embed → Qdrant → Jina rerank
  - [ ] **asyncio.gather**:
    - [ ] Reply agent LLM (80–300 tok depending on intent):
      - `knowledge_agent` → `RECEPTIONIST_SYSTEM_PROMPT` + RAG context (300 tok)
      - `qualifier_agent` → qualifier system (180 tok)
      - `escalation_agent` → escalation system (120 tok)
    - [ ] `extract_fields_from_message` LLM (100 tok, temp 0.0) → `{name, phone, email, budget_min/max, area_preference, bedrooms_needed, timeline, intent}`
  - [ ] `capture_lead_fields` if any non-null fields:
    - [ ] `INSERT INTO leads` (source=`chat`) or `UPDATE leads SET …`
  - [ ] If escalate: `UPDATE leads SET needs_human=True, status="contacted"`
  - [ ] `GoogleTranslator` → reply in user's language
- [ ] Rule-based `score_message()` → `compute_total_delta()` → `score_delta`
- [ ] `_persist_turn(session_id, company_id, …)`:
  - [ ] `SELECT id, transcript FROM conversations WHERE session_id=…`
  - [ ] If exists: `UPDATE conversations SET transcript=[…+new turns]`
  - [ ] Else: `INSERT INTO conversations` (channel=`chat`)
  - [ ] If `lead_id` and `score_delta ≠ 0`: `Supabase RPC increment_lead_score(lead_id, delta)`
- [ ] Append turns to history; `Redis SET chat:session:{session_id}` TTL 1800 s
- [ ] If no lead_id + score_delta > 0 → `_get_or_create_session_lead`:
  - [ ] `SELECT lead_id FROM conversations WHERE session_id=…`
  - [ ] If none: `INSERT INTO leads` → `UPDATE conversations SET lead_id=…`
- **DB reads**: Redis `chat:session:…`, `conversations` (session_id), `companies` (full record), Qdrant, `leads` (if updating)
- **DB writes**: Redis `chat:session:…` (TTL 1800 s), `conversations` (INSERT/UPDATE), `leads` (upsert), Supabase RPC `increment_lead_score`
- **Ext**: OpenAI Embeddings, Jina, LLM `claude-sonnet-4-6` ×3, Google Translate
- **Response**: `{reply, session_id, lead_id?, confidence, language}`

### POST /demo/voice  _(the browser voice demo)_

- [ ] **Auth**: NONE. Per-IP budget via `_demo_rate_limit()` in Redis — these
      endpoints spend money on every call, so an unthrottled one is a bill
      (AUDIT.md H3).
- [ ] Body: multipart — `audio` (webm/opus from the browser), `lang`, `history`
- [ ] `transcribe_file()` → **Deepgram nova-2**
- [ ] `anormalize_for_llm()` — a no-op while one language is configured
- [ ] `complete()` → **gpt-4o-mini**, voice persona (1-2 sentences)
- [ ] `synthesize_browser()` → **Deepgram Aura-2**. The reply is split on clause
      boundaries and the pieces are synthesised CONCURRENTLY, then joined as
      MP3 frames. Aura-2 generation scales with text length and was ~70% of the
      turn; this halves it without changing the voice.
- **Response**: `{transcript, reply, historyUser, historyAssistant, audio (base64), audioMime}`
- **Note**: `audioMime` is not cosmetic — the parallel path and the single-shot
  fallback can return different containers, and the widgets read it rather than
  assuming MP3.

## PUBLIC API ROUTES  `prefix /v1`  _(API-key auth, not session auth)_

The machine-facing surface an agency integrates against. Every route
authenticates with `Authorization: Bearer nxd_live_...` rather than a dashboard
session, resolves the key to a `company_id`, and scopes every query to it.

- [ ] **Auth**: API key. `_validate_api_key()` reads `api_keys` for
      `company_id, scopes, revoked_at`; a revoked or unknown key is a 401.
      `last_used_at` is written on a throttle rather than every call, which
      previously doubled the round-trips and churned the row (AUDIT.md M10).
- [ ] `GET /v1/leads` · `POST /v1/leads` — read and create leads
- [ ] `GET /v1/appointments` — upcoming appointments
- [ ] `GET /v1/properties` — the company's listings
- **DB**: `api_keys` (auth), then `leads` / `appointments` / `properties`,
  every query filtered by the key's `company_id`
- **Tenancy**: the key IS the tenant boundary here — there is no session to
  fall back on, so a missing filter is a cross-tenant read

### Known gaps / issues identified during audit

- [ ] `DELETE /properties/{property_id}` — Qdrant chunks orphaned (not deleted)
- [ ] `DELETE /rag/documents/{doc_id}` — Supabase Storage file orphaned (not deleted)
- [ ] `PATCH /leads/appointments/{appt_id}` — Google Calendar event not updated on reschedule
- [ ] `POST /voice/inbound` — single-tenant fallback (`LIMIT 1`) means any company gets voice calls if their phone doesn't match
- [ ] `GET /admin/invite-quick` — no rate limiting; token is compared via `hmac.compare_digest` but exposed as URL param (appears in server access logs)
- [ ] `WS /voice/stream` — Twilio signature not verified on the WebSocket itself (only on `/voice/inbound`); any client who knows the `call_sid` can connect
- [ ] `POST /demo/chat` — falls back to hardcoded "Palm Elite Properties" persona if `resolve_demo_company()` returns None
- [ ] `POST /chat/message` — no auth; company_id is caller-supplied and trusted without ownership check
- [ ] TELEPHONY_AUTH_TOKEN and RESEND_WEBHOOK_SECRET blanks silently disable webhook auth in production
